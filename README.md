# TaskManager Java - Capacita iRede

Projeto desenvolvido em Java para o curso Capacita iRede.

## Versao inicial

A primeira versao do sistema foi desenvolvida em console, permitindo:

- criar tarefas comuns;
- criar tarefas prioritarias;
- listar tarefas;
- marcar tarefas como concluidas;
- remover tarefas;
- tratar entradas invalidas.

## Evolucao intermediaria

Nesta etapa, o projeto sera evoluido para utilizar:

- JavaFX para interface grafica;
- JDBC para persistencia em banco de dados;
- Generics para reaproveitamento de codigo;
- JUnit para testes automatizados.
